# 2D Scene Guide

Creating 2D scenes with Camera2d, colored meshes, sprites, and 2D primitives.

## Camera2d

Use `Camera2d` instead of `Camera3d`. DistanceFog and shadows don't apply in 2D, but **Bloom works** — add `Tonemapping` + `Bloom()` and use HDR colors (values > 1.0) to trigger glow. The coordinate system is screen-space: +X right, +Y up, origin at center.

```python
# Basic camera
commands.spawn(Camera2d(), Transform.IDENTITY)

# Camera with bloom (for glowing effects)
from pybevy.camera import Bloom, Tonemapping
commands.spawn(Camera2d(), Tonemapping.TONY_MC_MAPFACE, Bloom())
```

## Two Rendering Paths

### 1. Mesh2d + ColorMaterial (procedural shapes)

For colored geometric shapes without textures. Uses `Mesh2d` + `MeshMaterial2d[ColorMaterial]`:

```python
mesh = meshes.add(Circle(30.0))
mat = materials.add(ColorMaterial(color=Color.srgb(0.2, 0.8, 0.4)))
commands.spawn(Mesh2d(mesh), MeshMaterial2d(mat), Transform.from_xyz(0.0, 0.0, 0.0))
```

**System parameter types:**
```python
def setup(
    commands: Commands,
    meshes: ResMut[Assets[Mesh]],
    materials: ResMut[Assets[ColorMaterial]],  # NOT Assets[StandardMaterial]
) -> None:
```

### 2. Sprite (image-based)

For texture/image rendering:

```python
# From an image file
image = asset_server.load("character.png")
commands.spawn(Sprite.from_image(image), Transform.from_xyz(0.0, 0.0, 0.0))

# Solid color rectangle (no image needed)
commands.spawn(
    Sprite.from_color(Color.srgb(1.0, 0.0, 0.0), Vec2(100.0, 50.0)),
    Transform.from_xyz(0.0, 0.0, 0.0),
)
```

### When to use which

| Need | Use |
|------|-----|
| Colored geometric shapes | `Mesh2d` + `ColorMaterial` |
| Image/texture display | `Sprite.from_image()` |
| Simple colored rectangles | `Sprite.from_color()` or `Mesh2d` + `Rectangle` |
| Sprite sheets | `Sprite.from_atlas_image()` |

## 2D Mesh Primitives

All primitives implement `Meshable` — pass directly to `meshes.add()`.

| Primitive | Constructor | Notes |
|-----------|------------|-------|
| `Circle` | `Circle(radius)` | Filled circle |
| `Rectangle` | `Rectangle(width, height)` | Filled rectangle |
| `RegularPolygon` | `RegularPolygon(circumradius, sides)` | sides >= 3 |
| `Triangle2d` | `Triangle2d(Vec2, Vec2, Vec2)` | Three vertices |
| `Ellipse` | `Ellipse(Vec2(half_width, half_height))` | Axis-aligned ellipse |
| `Annulus` | `Annulus(inner_radius, outer_radius)` | Ring shape |
| `Capsule2d` | `Capsule2d(radius, half_length)` | Pill shape |
| `Rhombus` | `Rhombus(half_diag_h, half_diag_v)` | Diamond shape |
| `CircularSector` | `CircularSector(radius, half_angle)` | Pie slice (half_angle; use `from_radians(r, full_angle)` for full angle) |
| `CircularSegment` | `CircularSegment(radius, half_angle)` | Arc segment (half_angle; use `from_radians(r, full_angle)` for full angle) |
| `Segment2d` | `Segment2d(Vec2, Vec2)` | Line segment |

```python
# Examples
meshes.add(Circle(30.0))
meshes.add(Rectangle(60.0, 40.0))
meshes.add(RegularPolygon(25.0, 6))   # Hexagon
meshes.add(RegularPolygon(25.0, 3))   # Triangle
meshes.add(Annulus(20.0, 30.0))       # Ring
```

## Z-Ordering

In 2D, use `Transform.translation.z` to control draw order. Higher Z renders on top:

```python
# Background (behind)
commands.spawn(Mesh2d(bg_mesh), MeshMaterial2d(bg_mat), Transform.from_xyz(0.0, 0.0, -1.0))

# Foreground (in front)
commands.spawn(Mesh2d(fg_mesh), MeshMaterial2d(fg_mat), Transform.from_xyz(0.0, 0.0, 1.0))
```

**Suggested layer convention:**
- Background: z = -10
- Game world: z = 0
- Foreground effects: z = 1–5
- UI overlays: z = 10+

## ColorMaterial

`ColorMaterial` is the 2D equivalent of `StandardMaterial`. It supports color and optional texture:

```python
# Solid color
materials.add(ColorMaterial(color=Color.srgb(0.8, 0.2, 0.2)))

# Semi-transparent
materials.add(ColorMaterial(color=Color.srgba(0.3, 0.5, 0.8, 0.5)))

# With texture
materials.add(ColorMaterial(texture=asset_server.load("texture.png")))

# Tinted texture
materials.add(ColorMaterial(color=Color.srgb(1.0, 0.5, 0.5), texture=image_handle))

# HDR color (triggers bloom glow when Bloom is enabled on camera)
# Color values > 1.0 are the primary way to create glow effects in 2D.
# srgb(2.0, 0.5, 0.5) = glowing red, not just brighter red.
materials.add(ColorMaterial(color=Color.srgb(5.0, 2.0, 0.0)))  # bright orange glow
```

## Minimal 2D Scene Template

```python
import math
from pybevy.prelude import *

def setup(
    commands: Commands,
    meshes: ResMut[Assets[Mesh]],
    materials: ResMut[Assets[ColorMaterial]],
) -> None:
    commands.spawn(Camera2d(), Transform.IDENTITY)

    # A colored circle
    mesh = meshes.add(Circle(40.0))
    mat = materials.add(ColorMaterial(color=Color.srgb(1.0, 0.85, 0.2)))
    commands.spawn(Mesh2d(mesh), MeshMaterial2d(mat), Transform.IDENTITY)

@entrypoint
def main(app: App) -> App:
    app.add_plugins(DefaultPlugins)
    app.add_systems(Startup, setup)
    return app

if __name__ == "__main__":
    main().run()
```

## Animated 2D Example

A scene with bloom, HDR glow, and animated entities. Shows the 2D-specific setup — for general animation patterns (components, systems, `time.elapsed_secs()` vs `time.delta_secs()`), see `guide://recipes/animated`.

**Important:** For oscillating motion, always compute absolute positions from a stored base — never use incremental offsets (`translation.x += delta`), which drift over time.

```python
import math
from dataclasses import dataclass
from pybevy.prelude import *
from pybevy.camera import Bloom, Tonemapping

@component
@dataclass
class Orbiting(Component):
    base_x: float = 0.0
    base_y: float = 0.0
    phase: float = 0.0
    speed: float = 1.0
    radius: float = 40.0

def setup(
    commands: Commands,
    meshes: ResMut[Assets[Mesh]],
    materials: ResMut[Assets[ColorMaterial]],
) -> None:
    commands.spawn(Camera2d(), Tonemapping.TONY_MC_MAPFACE, Bloom())

    # Background
    bg = meshes.add(Rectangle(1200.0, 800.0))
    commands.spawn(Mesh2d(bg),
                   MeshMaterial2d(materials.add(ColorMaterial(color=Color.srgb(0.02, 0.02, 0.06)))),
                   Transform.from_xyz(0.0, 0.0, -10.0))

    # Glowing orbs with HDR bloom
    orb = meshes.add(Circle(8.0))
    colors = [Color.srgb(4.0, 1.0, 0.2), Color.srgb(0.5, 3.0, 0.5), Color.srgb(1.0, 1.0, 4.0)]
    for i, color in enumerate(colors):
        mat = materials.add(ColorMaterial(color=color))
        commands.spawn(
            Mesh2d(orb), MeshMaterial2d(mat),
            Transform.from_xyz(0.0, 0.0, 1.0),
            Orbiting(phase=i * math.tau / 3.0, speed=0.8, radius=80.0),
        )

def animate(query: Query[tuple[Mut[Transform], Orbiting]], time: Res[Time]) -> None:
    t = time.elapsed_secs()
    for transform, orb in query:
        x = orb.base_x + math.sin(t * orb.speed + orb.phase) * orb.radius
        y = orb.base_y + math.cos(t * orb.speed + orb.phase) * orb.radius
        transform.translation = Vec3(x, y, transform.translation.z)

@entrypoint
def main(app: App) -> App:
    app.add_plugins(DefaultPlugins)
    app.add_systems(Startup, setup)
    app.add_systems(Update, animate)
    return app

if __name__ == "__main__":
    main().run()
```

## Text in 2D Scenes

Use `Text2d` for world-space text rendered by `Camera2d`:

```python
from pybevy.text import Text2d, TextFont, TextColor

commands.spawn(Text2d("Hello!"), TextFont.from_font_size(32.0), Transform.from_xyz(0.0, 50.0, 0.0))
```

- Mutate at runtime via the `.text` property: `text2d.text = "new string"`
- **Not `.content`** — that's the UI `Text` component (see `guide://ui-text`)
- `Text2d` requires `Camera2d`. It will NOT render with `Camera3d`.

## Debug Camera Limitation

The MCP `capture_screenshot` tool's `position`/`look_at` parameters spawn a temporary 3D debug camera. This **does not work with 2D scenes** — you'll get a blank image. For 2D scenes, always use the default scene camera (omit `position`/`look_at`). Use `max_width` for higher resolution captures.

## Alpha Stacking

Multiple semi-transparent shapes overlapping in 2D produce **additive opacity** — each layer compounds. A circle with `alpha=0.05` looks fine alone, but 4 overlapping circles appear as `~0.20` opacity (much more visible than expected).

**Mitigation strategies:**
- Use very low alpha values (`0.01–0.02`) when shapes will overlap
- Stagger positions/phases in animations so fewer shapes overlap at any given frame
- Use fewer, larger shapes instead of many small overlapping ones

```python
# Too opaque when stacked (4 × 0.08 = ~0.30 visible opacity)
ColorMaterial(color=Color.srgba(0.3, 0.3, 0.3, 0.08))

# Better for overlapping shapes
ColorMaterial(color=Color.srgba(0.3, 0.3, 0.3, 0.015))
```

## Key Differences from 3D

| 3D | 2D |
|----|-----|
| `Camera3d` | `Camera2d` |
| `Mesh3d` + `MeshMaterial3d` | `Mesh2d` + `MeshMaterial2d` |
| `Assets[StandardMaterial]` | `Assets[ColorMaterial]` |
| Bloom | Works with `Tonemapping` + `Bloom()` + HDR colors (> 1.0) |
| DistanceFog, shadows | Not applicable |
| `Cuboid`, `Sphere`, `Cylinder` | `Circle`, `Rectangle`, `RegularPolygon` |
| Y-up, units in meters | Screen-space, units in pixels |
| Depth buffer for ordering | `Transform.z` for draw order |
